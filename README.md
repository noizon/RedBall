# 🔴 Red Ball Adventure

> Привет! Это мой пет-проект — **2D-платформер на Python**, в котором красный шарик путешествует по 20 уровням, сражается с врагами и боссами.

Проект начинался как обычная игра на Pygame, но со временем вырос в полноценную экосистему: теперь у него есть **веб-сервер на Flask**, который запускает игру, отдаёт статистику и позволяет скачать архив с игрой прямо из браузера.

---

## ✨ Что внутри

### 🎮 Игровая часть
*   **20 уровней** с разными темами: Лес, Лёд, Вулкан, Тёмный замок.
*   **4 уникальных босса** с разными стилями атак (Огненный, Ледяной, Водяной, Теневой).
*   **4 типа врагов**: обычные, танки, призраки, бегуны.
*   **Бонусы**: Ускорение, Щит, Магнит.
*   **Монеты и аптечки**, комбо-система, 15 достижений.
*   **Сохранение прогресса** и плавная камера с частицами.

### ⚙️ Техническая часть
*   **Python 3.8+** и **Pygame** для игры.
*   **Flask** для веб-сервера.
*   **Кастомный веб-интерфейс** на HTML/CSS/JS с анимированным фоном, курсором-шариком и звуками через Web Audio API.
*   **API**: статистика запусков, скачиваний и таблица рекордов.
*   **Скачивание игры** в ZIP-архиве с готовым `start.bat` и инструкцией.

## 🚀 Как запустить

### Вариант 1. Только игра
```bash
git clone https://github.com/noizon/RedBall.git
cd RedBall
pip install pygame
python game.py
Вариант 2. Игра + веб-сервер (рекомендую)
bash
pip install -r requirements.txt
python server.py
Сервер сам откроет браузер на http://localhost:5000. Оттуда можно запустить игру, скачать её архив или посмотреть статистику.

📡 API (кратко)
GET /start_game — запуск игры.

GET /download_game — скачивание ZIP-архива.

GET /api/stats — статистика (JSON).

GET /api/records — таблица рекордов (JSON).

GET /api/info — информация о сервере.
